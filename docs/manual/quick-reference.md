# Quick reference

A normal printing session, start to finish:

1. Machine supplies on, then the laptop. Open the printer's page; all four chips green.
2. **Home Z**.
3. Fit the vat; set or check the film zero.
4. Fill the vat with resin.
5. For a laser job: eyewear, laser supply on, **Arm laser**.
6. **Jobs** → **Start print**.
7. Watch the **Print** tab. **Pause after layer** to inspect, **Stop print** to abandon, **STOP** in an emergency.
8. When the plate is at the top and the badge reads IDLE, remove the part.
9. After a failed print, **Clean vat**.
10. Laser supply off, **System** → **Shut down computer**, then the machine supplies.
